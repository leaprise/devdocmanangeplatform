    jlink（openjdk11/ 21）¶

    jlink用于创建小型jre，测试流程：

    openjdk11：¶

    jar -cvfe temp.jar com.example.Temp com ##将编译好的代码打包为jar包
jdeps --list-deps temp.jar ##检查依赖
jlink --output temp-mini-jre --add-modules java.base --module-path=/usr/lib/jvm/java-11-openjdk/jmods ##根据依赖生成小型jre

    openjdk21：¶

    [root@localhost specjbb-src]# jlink --output temp-mini-jre --add-modules java.base --module-path=/usr/lib/jvm/java-21-openjdk/jmods
[root@localhost specjbb-src]# ls temp-mini-jre/
bin  conf  include  legal  lib  man  release

    jmod（openjdk11/21）¶

    用于生成jmod模块。

    先创建模块化的代码：在同一个包除了编写普通的类还要编写module-info.java

    openjdk11：¶

    模块化编译： 

    javac -d mods/com.example src/module-info.java src/com/example/Temp.java
image.png

运行模块：

java --module-path mods -m com.example/com.example.Temp

测试把模块生成为jmod模块：

jmod create temp.jmod --class-path mods/com.example/

    openjdk21：¶

    [root@localhost my-pro]# javac -d mods src/module1/module-info.java src/module1/Main.java
src/module1/module-info.java:1: warning: [module] module name component module1 should avoid terminal digits
[root@localhost my-pro]# ls mods/module
module1/           module-info.class
[root@localhost my-pro]# ls mods/module1/

[root@localhost my-pro]# java --module-path mods -m module1/module1.Main

    用于调试java进程。

    运行jar包时添加供调试用的socket端口 

    java -agentlib:jdwp=transport=dt_socket,server=y,suspend=n,address=5005 \

    jstatd（openjdk 1.8.0/11/21）¶

    相当于jstat后台进程，可用于远程连接查看进程信息，比如远程打开visualVM连接jstatd端口，可查看可视化的内存使用情况等信息。

    创建权限赋予文件jstatd.all.policy

    openjdk1.8.0写入如下内容： 

    grant codebase "file:/usr/lib/jvm/java-1.8.0-openjdk/lib/tools.jar" {
        permission java.security.AllPermission;
};
    openjdk11/21写入如下内容： 
    grant codebase "jrt:/jdk.jstatd" {
        permission java.security.AllPermission;
};

grant codebase "jrt:/jdk.internal.jvmstat" {
       permission java.security.AllPermission;
};
    启动jstatd， 
    nohup jstatd -J-Djava.rmi.server.hostname=10.0.2.15 -J-Djava.security.policy=./jstatd.all.policy -p 1099 &
image.png
    已经启动成功，可以远程连接1099端口，查看jvm进程的具体信息

    rmid（openjdk 1.8.0/11）¶

    用于分布式java进程远程通信的工具。

    启动rmid进程 

    nohup rmid -J-Dsun.rmi.activation.execPolicy=none -port 1099 &
image.png
    启动成功。

    serialver（openjdk 1.8.0/11/21）¶

    生成序列码的工具。

    准备测试文件，实现Serializable接口，才可序列化 

    package com.example;
import java.io.Serializable;
public class Temp implements Serializable{
    public static void main(String[] args) {
        System.out.println("Hello wold!");
    }
}


    serialver com.example.Temp ##生成序列化id
