    Hadoop 验证¶

    环境¶

    环境：riscv openEuler24.03
Hadoop版本: 3.4.0

    简介¶

    Hadoop是一个开源的分布式系统基础架构，核心设计思想是“分而治之”，旨在使用普通的计算机集群处理海量数据。它解决了传统系统无法有效存储与计算互联网时代产生的巨量非结构化和半结构化数据的难题。Hadoop的核心主要由三个组件构成。首先是HDFS（Hadoop Distributed File System），即分布式文件系统。它将超大文件自动切分成多个数据块，并冗余存储在整个集群的多台机器上，提供了高可靠、高吞吐量的数据存储服务。其次是MapReduce，这是一种编程模型，负责分布式并行计算。第三是YARN，作为Hadoop 2.0引入的资源调度平台，它负责集群的资源管理和作业调度，使得Hadoop可以超越MapReduce，运行更多种类的计算框架，如Spark、Flink等，极大地提升了平台的通用性和效率。

    安装¶

    欧拉镜像修改hostname，免得后面跟hadoop默认配置冲突¶

    nano /etc/hostname
修改为localhost
reboot

    创建hadoop账户¶

    useradd hadoop
chown -R hadoop:hadoop /opt/hadoop-3.4.0
passwd hadoop 
su hadoop
nano ~/.bashrc
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-11.0.11.9-9.oe2203.riscv64/

    进入hadoop目录,做好配置¶

    cd /opt/hadoop-3.4.0/
# 配置免密登录ssh
[hadoop@localhost hadoop-3.4.0]$ mkdir data
[hadoop@localhost hadoop-3.4.0]$ ssh-keygen -t rsa -P '' -f ~/.ssh/id_rsa
[hadoop@localhost hadoop-3.4.0]$ cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
[hadoop@localhost hadoop-3.4.0]$ chmod 0600 ~/.ssh/authorized_keys
[hadoop@localhost hadoop-3.4.0]$ vi etc/hadoop/core-site.xml
<configuration>
    <property>
        <name>fs.defaultFS</name>
        <value>hdfs://localhost:9000</value>
    </property>
    <property>
        <name>hadoop.tmp.dir</name>
        <value>/opt/hadoop-3.4.0/data/tmp</value>    这里我们指定存放在hadoop根目录下的data文件夹下
    </property>
</configuration>

[hadoop@localhost hadoop-3.4.0]$ vi etc/hadoop/hdfs-site.xml
<configuration>
    <property>
        <name>dfs.replication</name>
        <value>1</value>
    </property>
</configuration>
