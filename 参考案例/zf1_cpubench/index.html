    珠峰服务器荣获CPU测评基准工具CPUBench V1版本“性能卓越奖”¶

    2025年11月5日至7日，备受业界瞩目的**2025新产业标准化领航论坛**在上海隆重举行。论坛由中国电子技术标准化研究院（即工信部电子第四研究院，简称电子四院）联合上海赛西科技发展有限责任公司共同举办。工信部副部长熊继军，上海市委常委、副市长陈杰出席开幕式并致辞。

    论坛以“标领新途，智绘未来”为核心，旨在通过推动关键技术的标准化进程，构建开放协同的产业生态，为我国新质生产力的发展注入强劲动力。

    载誉而归，性能标杆权威认证¶

    在本次论坛备受关注的“标准化成果表彰”环节，中兴微电子凭借在CPUBench V1版本评测的优异表现（IntConcurrent整机得分425.5，FloatConcurrent整机得分381.9），其**服务器产品ZTE R5310G3**荣膺大会颁发的“性能卓越奖”。这一殊荣不仅是对公司技术研发实力的高度肯定，更是对中兴微在推动产业标准化进程中所作贡献的权威认可。

    架构解析，运行流程全面透视¶

    CPU测评基准工具CPUBench是在工信部电子司指导下，由电子四院牵头联合国内CPU研制企业、整机系统厂商及用户单位自主研制的通用处理器性能基准测评工具。CPUBench 测试框架采用 Python 语言开发,模块化设计,兼容 x86_64、aarch64、RISC-V（V1.3新增支持）、ppc64le、sw_64 和 loongarch64 等多种 CPU 架构。该工具对于指导通用计算 CPU、服务器等计算产品的设计优化、规格选型和市场采购等工作,对计算产业的发展具有重要的牵引意义。

    CPUbench工具总体框架如下图所示，主要包括：负载模块、配置模块、控制模块、通用模块和平台模块五个部分。当在被测系统（SUT,System UnderTest）上运行测试套件或部分测试负载时，测试框架将自动执行以下流程: 1. 检查被测系统是否具备必要的依赖，如gcc、g++、gfortran和jdk等； 2. 提取内置工具，如cmake和python3； 3. 解析命令行和配置文件的参数； 4. 核心程序代码的防篡改检查； 5. 编译、构建和运行所需的测试套件或测试负载； 6. 运行后校验每个测试负载结果的正确性； 7. 计算性能得分,收集被测对象的软硬件信息，并汇总到测试报告中。

    技术共享，推动产业协同发展¶

    中兴微电子正深度参与工具相关的标准拟定和优化验证工作： 1. 在“国家标准《半导体集成电路中央处理器（CPU）性能技术规范》”的公开意见征集活动中，中兴微电子提出3条修改建议最终被新标准采纳，包括：numa功能支持，java21支持，以及单实例内存需求限制。这些改动将进一步推动后续CPUBench工具在易用性、兼容性等方面的提升和改进。 2. 在CPUBench V1.3版本研发过程中，中兴微电子基于算能SG2042平台对CPUBench 1.3.1/1.3.2版本在RISC-V架构上进行了可用性验证；在验证过程中发现并反馈了4个关键工具链适配问题，涉及GCC/JDK版本对CPUBench在RISC-V架构上的兼容性。其结果被收录于CPUBench 1.3版本的发布文章中，为RISC-V生态完善了重要的性能基准测试数据。 目前，中兴微电子已经成为CPUBench版本源码gitee组织（计算性能基准专委会）成员之一，正在参与未来CPUBench版本的新用例开发工作，将重点聚焦智算新场景，为基准工具注入新活力。

    结语¶

    推动技术标准化与共享是产业繁荣的基石。本次论坛最新发布的CPU测评基准V1.3将向业界开放共享，为产业链上下游提供可靠的性能标尺，减少重复开发与测评成本，助力提升芯片产品设计与应用优化的效率，共同推动我国芯片产业高质量发展。 此次获奖既是里程碑，更是新起点。中兴微电子将继续秉持“聚力同行，共筑智能新未来”的理念，深耕芯片核心技术，积极参与产业标准制定，与伙伴携手共建繁荣的新生态。
